# Legado 书源规则：官方解析器对照笔记

参考：https://github.com/legadoTeam/legado-rule （`book-source-rule-parser`，MIT）

这是一份把 Legado 规则语法**规范化**成显式前缀的解析器实现，比社区书源的写法更规整，
适合当作「语法规范」来对照我们的 `rules.js`。

---

## 1 语法全貌

### 1.1 六种选择器（显式前缀）

| 前缀 | 含义 | 例 |
| --- | --- | --- |
| `@css:` | CSS 选择器 | `@css:.title@text` |
| `@xpath:` | XPath | `@xpath://h1/text()` |
| `@json:` | JSONPath | `@json:$.data.books[0].title` |
| `@regex:` | 正则匹配 | `@regex:ISBN:([\d-]+)` |
| `@js:` | 沙箱执行 JS | `@js:document.title` |
| `@text:` | 常量文本 | `@text: - 作者：` |

### 1.2 取值尾缀

`@text`（文本）、`@html`（innerHTML）、`@outerHTML`、`@innerText`（去多余空白）、
`@length`、`@src`、`@href`、以及任意属性名（如 `@data-id`）。

### 1.3 三种操作符

| 操作符 | 语义 | 例 |
| --- | --- | --- |
| `\|\|` | 回退：按顺序试，取第一个非空 | `@css:.title@text \|\| @text:未知` |
| `&&` | 拼接：把多个结果按顺序连起来 | `@text:【 && @css:.cat@text && @text:】` |
| `##` | 净化：`##正则##替换`，只写一个 `##正则##` 表示删掉 | `@css:.price@text##\d+\.\d+` |

括号可分组：`(@css:.a@text || @text:x) && @text: - && @css:.b@text`。

## 2 我们的实现（rules.js）现状

已支持：

- `class.` / `tag.` / `id.` / `text.` 前缀 + `@` 链（`id.list@p@a`）
- 索引：`a.0`、`p!0`（倒数）、`li.1:2:3`
- JSONPath：`$..book_data[*]`、`$.a.b`、`{{$.x}}`、`{$..x}`
- `<js>` 与 `@@` 链（正文规则）
- `||` 回退、`##正则##替换`
- `@text` / `@href` / `@src` / `@html`

实测缺失（2026-11-08 验证）：

| 写法 | 我们 | 官方 |
| --- | --- | --- |
| `@css:.title@text` | ✗ 空 | ✓ |
| `@xpath://h1/text()` | ✗ 空 | ✓ |
| `@json:$.a.b` | ✗ 空 | ✓ |
| `@text: - 作者：`（常量片段） | ✗ | ✓ |
| `&& 拼接常量` | ✗ 只返回第一段 | ✓ |
| `@innerText` / `@length` / `@outerHTML` | ✗ | ✓ |

`##正则##替换`、`||` 回退是正常的。

## 3 如果要补齐，改动点

1. **显式前缀**：在 `parseSegment` 前加一层前缀识别
   - `@css:` → 当作 CSS 选择器（去掉前缀）
   - `@xpath:` → 走 `xpath.js`
   - `@json:` → 走 `jsonPath`
   - `@regex:` → 正则提取（`@regex:pattern` 或 `@regex:group:pattern`）
   - `@text:` → 直接返回常量
   注意和我们自己的 `@` 链分隔符冲突：`@css:.a@text` 里第一个 `@` 是前缀，后面的 `@text` 是取值尾缀。

2. **`&&` 拼接语义**：现在 `&&` 被当作多段串联，但没有把各段结果 join 起来；
   应改为「逐段求值 → 非空结果按顺序拼接」。

3. **常量片段**：`@text:xxx` 在 `&&` 链里作为字面量参与拼接。

4. **更多取值尾缀**：`@innerText`、`@length`、`@outerHTML`。

这四项都不影响现有书源（它们用 `class.` 前缀），属于纯增量兼容。
