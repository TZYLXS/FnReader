# Legado 阅读 · fnOS 网页版（FPK）

把安卓「阅读 3.0 / Legado」的使用体验搬到飞牛 fnOS 上：**不用装安卓模拟器**，直接在 fnOS 桌面点开就是一个网页书架，支持导入 Legado 书源、搜索、加书架、看目录和正文。

- 安装包：`legado-web.fpk`（v1.0.1，约 551 KB）
- 已在测试机 `10.5.4.70` 安装并运行

---

## 1. 为什么不是直接编译原安卓源码

原项目是 Kotlin + Jetpack Compose 的原生安卓 App，界面无法在浏览器里渲染；Android 模拟器（redroid 等）在 NAS 上需要 KVM、资源占用大、手机端体验也差。

因此这里采用**复用 Legado 书源协议、重写运行层**的方案：

| 层 | 做法 |
| --- | --- |
| 书源规则引擎 | 用 JavaScript 重新实现 Legado 规则语法（CSS / XPath / JSONPath / 正则 / `@js:` 沙箱） |
| 服务端 | Node.js 单文件（esbuild 打包），读写 JSON 数据 |
| 前端 | 移动端优先的单页应用（书架 / 搜索 / 阅读器 / 书源管理 / 设置） |
| 打包 | fnOS FPK：统一网关入口 + 端口直连双入口，依赖系统 `nodejs_v22` |

所以你导入的 **Legado 书源 JSON 可以直接用**，不需要改格式。

## 2. 安装

### 方式 A：应用中心手动安装（推荐）

1. 打开 fnOS「应用中心」→ 右上角/设置中的「手动安装」
2. 选择 `legado-web.fpk`
3. 安装完成后，桌面会出现「Legado 阅读」图标

### 方式 B：命令行

```bash
appcenter-cli install-fpk /path/to/legado-web.fpk
appcenter-cli start legado-web
```

> 依赖 `nodejs_v22`，安装时会由应用中心自动拉起；如果启动失败，先确认该依赖已安装。

## 3. 打开方式

| 入口 | 地址 | 说明 |
| --- | --- | --- |
| 桌面图标（网关） | `/app/legado-web/` | 走 fnOS 统一网关，复用 NAS 登录态，推荐 |
| 直连端口 | `http://设备IP:1122/` | 不校验 NAS 登录，适合局域网/调试 |

桌面图标默认打开网关入口；`noDisplay` 的「直连端口」入口只在需要时使用。

## 4. 使用

1. **书源** → 右上角「导入」：
   - 粘贴 Legado 书源 JSON（数组或单个对象）
   - 或填书源订阅链接
   - 或选择本地 `.json` 文件
2. **搜索** → 输入书名/作者，可选「全部书源」或指定某个源；结果边搜边出
3. 点「加入书架」→ 自动拉取目录
4. **书架** → 点书封继续阅读；长按书封可删除
5. 阅读页：上一章/下一章、右上角 `☰` 目录、`Aa` 调整主题/字号/行距；进度自动保存

## 5. 兼容范围

已实现（按 Legado 3.x 规则语义）：

- 规则连接：`||` 备选、`&&` 拼接、`{{key}}` / `{{page}}` 变量
- 选择器链：`id.chapterlist@p@a`、`.btn@a.0@href`、`span.title@text`、`[property$=author]@content`
- 前缀写法：`class.x` / `tag.a` / `id.x` / `text.查看完整目录`
- 索引：`a.0`、`p!0`、`li.1:2:3`、`.-1`
- XPath：`//div[@class="x"]/a/@href`、`@XPath:`
- JSON：`$.data.list[*]`、`data.books`、嵌套 JSON 字符串、`{{$.field}}`
- 取值：`@text` `@html` `@href` `@src` `@textNodes` `@ownText`，以及裸写 `text` / `href`
- 变量：`@put:{key: rule}` / `@get:{key}` / `{{var}}`
- 正则：`rule:regex`、`##替换##`
- 脚本：`@js:`（vm 沙箱，`java.ajax` / `base64` / `md5` / `put/get` / `result` / `baseUrl` / `book` / `source`）
- 流程：搜索（相对地址、GET/POST、单引号配置、charset）、详情、目录、正文（翻页、`replaceRegex`）

已知限制（这类书源需要 WebView / App 接口，服务端无法实现）：

- `{"webView": true}` 的源；页面由 JS 动态渲染（如目录靠 AJAX 加载）
- 需要签名算法、登录态、加密接口的 API 源
- 发现页（`exploreUrl`）、RSS、本地 TXT/EPUB、朗读、换源
- 正文只保留文字，图片忽略

### 书源太多怎么办

「书源」页支持按名称/地址/分组筛选，点「检测」会对**当前筛选结果**用热门书名试搜一遍，标出「可用 / 无结果 / 不可用」，
检测完点「停用未通过」即可只留下能用的源；搜索页随后默认走「仅可用」，速度快很多。

## 6. 数据与目录

| 内容 | 位置 |
| --- | --- |
| 应用文件 | `/var/apps/legado-web/target/`（→ `/vol{n}/@appcenter/legado-web`） |
| 数据（书源/书架/进度/设置） | `/var/apps/legado-web/var/`（→ `/vol{n}/@appdata/legado-web`） |
| 运行日志 | `/var/apps/legado-web/var/app.log` |

卸载会保留数据目录，重新安装后书架和书源仍在；需要彻底清理时手动删除 `@appdata/legado-web`。

### 缓存

- 章节正文缓存在 `/var/apps/legado-web/var/cache/`（默认保留 14 天，超过 200MB 自动清理旧文件）
- 打开一章后会后台预取后面两章，翻页基本即时完成
- 想强制重新抓取某章：删掉对应缓存目录，或在书架长按「刷新目录」后重进

## 7. 源码与重新打包

```
work/fnos-legado/            # FPK 工程
├── manifest                 # appname=legado-web, 依赖 nodejs_v22, 端口 1122
├── config/privilege         # run-as=package（legado 用户）
├── config/resource          # 无额外系统资源
├── cmd/main                 # start/stop/status，拉起 node 服务
├── app/ui/config            # 网关入口 + 端口入口
├── app/server/src/*.js      # 服务端源码（规则引擎/抓取/存储/HTTP）
└── app/web/                 # 前端（index.html / app.js / style.css）

work/tools/build-fpk.sh      # 一键打包：esbuild → 组装 → fnpack build
```

重新打包：

```bash
bash work/tools/build-fpk.sh
# 产物：work/dist/legado-web.fpk
```

本地开发（不打包直接跑）：

```bash
cd work/fnos-legado/app/server
node src/server.js   # 需要 TRIM_* 环境变量，或直接 PORT=1122 LEGADO_DATA=./data
```

测试：`node work/test/e2e.js`（内置模拟书源站，覆盖搜索/目录/正文分页/进度，21 项断言）。

## 附：加载速度优化（v1.0.2）

| 场景 | 优化前 | 优化后 |
| --- | --- | --- |
| 阅读下一章 | 每次 1–3 s 网络请求 | 约 20 ms（预取命中） |
| 重看已读章节 | 重新抓取 | 约 12 ms（内存/磁盘缓存） |
| 重新打开应用后再读 | 重新抓取 | 直接命中磁盘缓存 |
| 首页静态资源 | 未压缩 | gzip（app.js 23KB → 7.6KB）+ ETag 304 |

实现方式：章节正文按「章节 URL」落盘缓存（`var/cache/`，14 天 TTL、200MB 上限自动清理），
打开一章后延迟 400 ms 后台预取后两章，同一章并发请求会合并为一次抓取；
静态资源加了 gzip 与 ETag，二次访问返回 304。

## 附：整本下载为 TXT（v1.0.3）

**入口**

- 书架：长按书封 → 菜单里点「下载整本为 TXT」
- 阅读页：右上角 `Aa` → 设置面板底部「整本下载」

**行为**

- 后台抓取全部章节，底部出现进度条（`已下载 x/y`），可随时取消
- 完成后浏览器自动下载 `<书名>.txt`
- 文件格式：UTF-8（带 BOM，Windows 记事本不乱码），开头是书名/作者/来源，之后每章「标题 + 正文」
- 文件同时保存在 NAS：`/var/apps/legado-web/var/downloads/<书名>.txt`

**速度**

下载复用阅读时的正文缓存与预取，读过的章节几乎瞬时；实测 922 章的书约 40 秒完成，生成 7.6MB TXT。
首次下载一本没读过的书，耗时取决于书源站点的响应速度。

**章节顺序**

部分站点把「最新章节」放在目录最前面，服务端会自动识别并翻转为正常阅读顺序；
分页造成的重复章节会按 URL 去重。

## 附：v1.1.0 新增

### 1. 封面

所有封面改走服务端代理 `/api/image`：带 Referer 抓取并落盘缓存，解决站点防盗链导致书架空白的问题。
没有封面（或加载失败）的书，会显示书名首字的占位封面。

### 2. 书源分组

「书源」页按 `bookSourceGroup` 折叠分组，组头显示数量；搜索页的书源筛选也改成**按分组**选择，
不再把几百个源平铺在搜索栏下面。

### 3. 下载统计

「设置 → 下载」显示已下载书籍数量，点进去是 `#/downloads` 列表：书名、作者、章节数、大小、时间，
可以重新保存到本机或删除（删除会同时删掉 NAS 上的文件）。

### 4. 订阅

底部新增「订阅」标签，支持直接添加 RSS 2.0 / Atom 地址，展示标题、时间、摘要，点条目在新窗口打开；
支持单个刷新、全部刷新、删除。

### 5. 下载位置

「设置 → 下载 → 保存位置」可选择：

- **应用数据目录**（默认，`var/downloads/`）
- **你在 fnOS 应用设置里授权的目录**（如 `/vol3/1000/DownLoad`）

授权方式：应用中心 → Legado 阅读 → 设置 → 授权目录，选一个文件夹；授权后重启一次应用，
下拉框里就会出现该目录。写入的文件权限固定为 `644`，文件管理器里能直接看到。

### 应用更名为「阅读」

## 附：v1.5.0 学术关键词识别

搜索时如果关键词带有学术特征，会自动**只搜「学术」分组书源**（OALib、arXiv），跳过几百个网络小说源：

- 中文词：机器学习、深度学习、神经网络、算法、模型、论文、文献、综述、数据集、实证、假设…
- 英文词：machine learning、neural network、dataset、hypothesis、empirical、survey、paper…
- 强短语（如「机器学习」「neural network」）单独出现即可判定

命中后搜索页会显示：`🎓 识别为学术查询（机器学习），只搜 2 个学术书源　改搜全部`

点「改搜全部」就对全量书源搜索（比如书名里恰好带「算法」的网络小说）。

学术模式下不受「仅可用」限制——学术源通常没跑过体检，但只要分组是「学术」就会被搜索。

## 附：版本与更新日志规范（自 1.6.8 起）

每次改动都按同一流程发版：

1. 递增 `manifest` 的版本号（补丁位 +1）
2. 在 `更新日志.txt` / `更新日志.md` 顶部插入一条该版本的说明
3. 更新 `app.js` 里「版本 Vx.y.z」的显示
4. 重新打包 `legado-web.fpk`，更新日志随包发布到 `docs/changelog.txt`

一条命令完成 1–4：

```bash
python tools/release.py "修复了 xxx；新增了 yyy" --build
# 只看计划、不写文件：
python tools/release.py "说明" --dry-run
```

注意：fnOS 的 `install-fpk` 不支持覆盖升级（会提示成功但文件不变），
所以发版安装需要「先 uninstall 再 install」；数据目录 `/vol2/@appdata/legado-web` 会保留。
